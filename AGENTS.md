# Quy tắc làm việc Trice

- Chỉ thay đổi trong thư mục Trice. Không sửa/cài đặt vào môi trường lab cũ.
- Đọc README.md, CONTRACTS.md, MERGE.md và guide đúng thành viên trước khi làm.
- Tôn trọng file ownership. Không đổi tên field/signature hoặc sửa file người khác âm thầm.
- Fixture là synthetic; không báo kết quả fixture thành AI/webcam thật.
- Không hardcode metric hoặc giả detection để qua nghiệm thu.
- Không thêm dependency/service nếu Python/OpenCV/framework hiện có giải quyết được.
- Output vào runs/, data/local/, evidence/; media và weights không commit mặc định.
- Không tự publish, push media, force-push hoặc nhận diện danh tính.
- Khi bàn giao ghi file thay đổi, interface giữ nguyên, lệnh đã chạy, kết quả và phần chưa làm.
